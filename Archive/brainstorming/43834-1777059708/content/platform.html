Where should this live?

This decides everything else — pick what fits best with how you actually browse.

A

Browser Extension

Click an icon in Chrome toolbar → paste link → tag it → done. Works across all 4 profiles. Zero context switch.

Pros

  • Lives where your links live
  • One-click save from any tab
  • Works across all Chrome profiles

Cons

  • Chrome only
  • Slightly more complex to build
B

Local Web App (runs on your laptop)

A small server on your machine, open it at localhost:3000 in any browser tab. Paste links, tag, save.

Pros

  • Simple to build
  • Works in any browser / any profile
  • Data stays on your machine

Cons

  • Need to keep server running
  • Extra step to open the app tab
C

Obsidian (vault-based)

Each saved link becomes a note in your Obsidian vault with tags and date. Search, filter, graph view.

Pros

  • Already installed if you use Obsidian
  • Powerful search and filtering
  • Links to other notes

Cons

  • Need Obsidian open to save links
  • Less browser-native
D

Use an existing open-source app

Something like Linkding, Hoarder, or Raindrop.io — self-hosted or free tier. No building needed.

Pros

  • Ready to use immediately
  • Browser extensions already exist
  • Features like auto-tagging, full-text search

Cons

  • Less customizable
  • Self-hosting needs Docker or a server
